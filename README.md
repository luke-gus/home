# lukegustafson.com

Personal homepage for Luke Gustafson, served by GitHub Pages at https://lukegustafson.com.

- `index.html`: single page (banner, briefing signup link, contact form).
- `banner-home.jpg`: banner, derived from `tn-briefing-assets/banner.jpg` with the headline replaced by the name.
- Contact form posts to FormSubmit (AJAX) for luke.gustafson@capitol.tn.gov; honeypot field `_honey`, captcha off, table template.
- Briefing signup lives in the separate `luke-gus/lukegustafson.com` repo at https://signup.lukegustafson.com.
